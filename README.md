# Portfolio Websites

Five professional, responsive website concepts built with HTML, CSS, and JavaScript.

## Projects

- `barbershop.html` — Barbershop Ostrava
- `fitness.html` — FitCoach
- `cafe.html` — Prague Café
- `autoservice.html` — Moravia Auto Service
- `flux.html` — Flux Payments

## Features

- Responsive design
- Mobile navigation
- Smooth scrolling
- Working contact / booking forms with validation
- FAQ accordions
- Image gallery with lightbox
- Interactive price calculator (auto service)

## Usage

Open any HTML file in a browser, or enable GitHub Pages from `Settings → Pages` and select the `main` branch.
